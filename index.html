Frequently asked questions.

Everything you need to know before wiring CodeMCP into your workflow.

What is the Model Context Protocol?

MCP is an open standard that lets AI assistants connect to external tools and data sources through a consistent interface, instead of a one-off integration per client.

Does CodeMCP send my code anywhere?

No. CodeMCP runs locally inside your project and exposes tools over MCP directly to the client you connect — your source stays on your machine.

Which AI clients can I use with it?

Any MCP-compatible client that supports project-scoped tool servers, including popular desktop and CLI-based AI assistants.

Can it modify files without me noticing?

Every write, edit, or delete goes through explicit project-scoped tool calls, so changes are visible and reviewable rather than silent.

Do I need to configure anything before running it?

No configuration is required to get started — run the command inside your project directory and the server is ready to connect.
